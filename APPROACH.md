# André Castanho - Approach on Tekever Code Challenge

- My first step was deciding which type of .NET project to use. I chose an ASP.NET Core Web API instead of MVC since the backend’s only purpose is to serve data to a separate React frontend. For the database, I chose MySQL, as it integrates easily with .NET and is the system I’m most experienced with. On the frontend, I used React with Vite because it offers fast builds, an efficient development environment and a modern toolchain that I’ve successfully used in previous projects. 
- The backend is structured into Models (data structure) and Controllers (business logic). For authentication, I implemented ASP.NET Identity Framework with JWT tokens that expire after 24 hours, ensuring secure session handling. The application models TV Shows, Seasons, Genres, and Actors using many-to-many relationships, enabling rich navigation between entities. Additionally, I included SeasonEpisodes with detailed fields such as rating and duration. Finally, I added an email service that, for development purposes, sends users recommended shows upon login if they have any show favorites.
